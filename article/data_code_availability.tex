\section*{Data and code availability}
All code, the data manifest with source URLs and SHA-256 hashes, the processed datasets
that can be redistributed, and the scripts that generate every table and figure of this
article are available at \url{https://github.com/[user]/[repo]} (archived release:
\url{https://doi.org/10.5281/zenodo.[id]}). Raw judicial texts are obtained from the
official open-data portals listed in the manifest and are not redistributed; the
repository re-downloads them. No personal data are released. Code is licensed under MIT;
text and figures under CC-BY~4.0.
